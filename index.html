核心功能

点击卡片查看详细说明。从文件管理到 APK 逆向，一套工具全搞定。

双面板文件管理
左右面板独立操作，一键复制/移动，支持 Root 目录与压缩包浏览。
smali 反编译 / 回编译
内置 baksmali + smali，直接编辑后汇编回 dex。
DEX 编辑与注入
字符串替换、日志注入、去签名校验、批量删类、合并提取。
ARSC 资源编辑
完整解析 resources.arsc，直接修改字符串池与资源条目。
APK 签名 & 共存
V1/V2/V3 签名、zipalign 优化、一键改包名实现共存。
jadx Java 反编译
内联 jadx 1.4.7，dex → Java 源码，方便阅读分析。
终端 & Root
自绘终端视图，支持 ANSI、256 色、双指缩放，Root shell 直接执行。
文本编辑器
MT管理器同款文本编辑器内核，16 种语法高亮，撤销重做、查找替换、括号配对。
压缩包 & 查看器
ZIP/7Z/TAR 浏览解压，图片、视频、音乐、字体、Hex 查看一应俱全。
液态玻璃 UI
8 个玻璃调色板，低版本自动降级，视觉与流畅兼得。
